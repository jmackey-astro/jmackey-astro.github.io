Writing pages with github.io
-------------------------------

+ Follow the instructions at [docs.github.com](https://docs.github.com/en/pages/quickstart) to set up a new repo and automatically deploy whenever you push changes to the main branch.

+ Default [page themes](https://github.com/orgs/pages-themes/repositories?type=all)

+ Test changes locally using Jekyll with Ruby: follow this [quickstart guide](https://jekyllrb.com/docs/)
